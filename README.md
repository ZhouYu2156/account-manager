# 账户管理器 (Account Manager)

一个安全、便捷的本地账户密码管理工具，基于Vue3和Element Plus开发，数据完全本地存储，无需联网，保障您的账户信息安全。

## 功能特性

- 🔐 **本地加密存储**：所有数据通过CryptoJS加密后存储在localStorage中，确保数据安全
- 🔑 **统一密码**：支持设置统一密码管理多个账户，无需记忆多个密码
- 🔍 **高效搜索**：支持按账户名称和类型进行快速搜索
- 📋 **复制粘贴**：一键复制用户名和密码，提高使用效率
- 🌙 **暗色模式**：支持亮色/暗色主题切换，保护视力
- 📱 **响应式设计**：适配桌面端和移动端不同设备
- 📤 **数据导入导出**：支持账户数据JSON格式导入导出，方便迁移和备份
- 🎭 **自定义盐值**：可自定义加密盐值，增强数据安全性

## 技术栈

- **Vue 3** (Composition API)
- **TypeScript**
- **Element Plus** 组件库
- **Pinia** 状态管理
- **CryptoJS** 加密库
- **LocalStorage** 本地存储

## 安全说明

- 所有账户数据均存储在您的浏览器本地，不会上传到任何服务器
- 数据使用AES加密算法和您设置的自定义盐值进行加密
- 请务必牢记您设置的盐值，盐值丢失将导致无法恢复已保存的账户信息
- 建议定期导出数据并安全保存，防止数据丢失

## 使用流程

1. **首次使用**：设置加密盐值（必须）
2. **添加账户**：点击左侧"添加账户"按钮
3. **账户管理**：
   - 支持设置统一密码（可选）
   - 支持查看/编辑/删除账户
   - 支持按类型/用户名搜索
4. **数据备份**：使用导出功能将数据导出为JSON文件保存

## 隐私承诺

本应用不收集任何用户数据，所有操作均在本地完成，无需担心隐私泄露问题。
